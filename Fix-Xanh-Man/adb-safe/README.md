# AdbSafe — tool chính

Xem **README tiếng Việt** ở thư mục cha: [`../README.md`](../README.md).

Chạy từ thư mục gốc dự án: double-click `Chay-AdbSafe.bat`, hoặc:

```bat
AdbSafe.bat
```

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\AdbSafe.ps1
```

Thứ tự TG82: **8** → Share → **2** → làm việc → **9** → Unshare.

Giảm rủi ro — **không** chữa 100% BSOD.
